Copy this, fill every bracket, do not delete blocks. One part = five beats.

```
SHOW: [THE STATION / piece number] PART: [n of 3]  CAST: [2-3 characters, names only]
LOGLINE OF THE PART (one sentence, what changes): [...]

PROMPT
Built on the convergent six blocks (shot, subject, action, light, audio, style)
with Vidu-style beat labels and Higgsfield-school negatives.

SHOT & CAMERA: [shot size] + [angle] + [ONE camera move], [lens/format if it matters]
SUBJECTS: [character 1: identity + wardrobe + which primary hue belongs to them],
          [character 2: same], [the object that will change]
ACTION (beat-labelled):
  (0-1.5s)  HOOK FRAME  - [the most legible image of the part: exactly what is
              in frame, and the question it asks]
  (1.5-4s)  STATE       - [who wants what, as ONE physical action]
  (4-7s)    TURN        - [the change: object moves / person enters / count wrong]
  (7-9s)    LINE        - [ONE spoken line, <= 9 words, spoken by NAMED character]
  (9-10s)   CLIFF FRAME - [the withheld fact, held. This frame becomes the first
              frame of the next part]
LIGHT: [one hard source, direction, and which surface it hits]
AUDIO: [the one hard sound that is NOT the line] + native dialogue as written
STYLE: [palette: two primaries + bone + ink] · flat fills · ink outline on every
       edge · [film/broadcast texture if any]
TEXT: NONE on screen. No title, no card, no subtitle, no watermark.
NEGATIVE: NO fisheye, NO plastic skin, NO commercial gloss, NO on-screen text,
          NO title cards, NO third primary hue, NO gradients, NO crowd,
          NO second voice event, NO lip movement outside 7-9s.

QC (all must pass)
[ ] a visible change every 1.5 s (5 changes minimum in 10 s)
[ ] hook frame is legible with the sound off AND does not need the previous part
[ ] exactly one spoken line, inside 7-9 s, <= 9 words, by a named character
[ ] cliff frame will be used as the first frame of part n+1 (save it)
[ ] two primaries maximum; character hues match the cast lock
[ ] no on-screen text anywhere
[ ] the part is funny or tense on its own; if neither, re-stage the TURN
```
