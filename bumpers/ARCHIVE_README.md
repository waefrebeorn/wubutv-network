# This directory is the archived bumper era

The bumper era closed 2026-10-20 by the owner's decree (see
`../archive/bumper-era/` — era summary and the decree verbatim).

The 1,153 mp4s here stay at these paths on purpose: the public CDN manifest
pins them here, and moving them would break the URLs. The era's label is the
paper trail in `archive/bumper-era/`, not a file move.
