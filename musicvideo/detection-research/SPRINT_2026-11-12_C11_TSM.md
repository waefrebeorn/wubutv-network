## What was built

`detection-research/c11_tsm/c11_tsm.c` — one file, `gcc -std=c11 -O2
-Wall -Wextra`, zero warnings, ASan+UBSan clean (leak in the `--words`
array found by ASan on the first run and fixed; re-run rc 0).

- **Modes:** `m7` (per-gap-targeted slicing + guard), `ola` (OLA256
  fallback), `hp` (paper's HP-TSM on a whole signal), `pv` (librosa PV —
  included for parity debugging only, NOT a core).
- **M7 scheduler:** port of `tsm_m4b.slice_tsm_targeted` — hit windows
  ±25 ms verbatim (merged when overlapping), placement by hit sample,
  per-gap alphas, 50 ms hit-tail lookback, head/tail gaps. Guard: head gap
  never flagged (no word body before the first hit); tail gap IS guarded
  (last word's body). HARD-flagged gaps get a truncated copy, WARN-flagged
  gaps stretch normally.
- **Gap DSP:** HPSS binary masks (STFT N=1024, ℓ=5) → PV N=4096 on
  harmonic + OLA N=256 on percussive → sum, with the 50 ms lookback
  (stretch pre+seg, trim the stretched pre).

**Lego:** WAV reader + FFT/ifft copied verbatim from `c11_mir/hpss.c`
(sprint 4/6). The STFT/ISTFT/PV/OLA/median are written fresh because the
prototype's exact librosa semantics differ from the c11_mir variants in
the details that decide parity — the five traps, each verified against the
installed librosa 1.0.0 source (`fw-venv`):

1. `librosa.stft` default `pad_mode` is `"constant"` (zero pad), not reflect.
2. `phase_vocoder` 1.0.0 takes RAW adjacent-frame phase differences — no
   expected-advance correction, no wrapping — and linearly interpolates
   magnitudes with extrapolation past the last frame.
3. The prototype's HPSS uses `scipy median_filter mode="nearest"` (edge
   repeat), not reflect.
4. `np.hanning` (OLA leg) is the SYMMETRIC window; librosa's Hann is periodic.
5. Python `round()` is round-half-to-even; C `round()` is half-away.
   `py_round()` replicates it for every sample-count computation.
