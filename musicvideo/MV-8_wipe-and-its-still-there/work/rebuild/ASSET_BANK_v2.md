## Global style lock (restated in every still and every Stage 4 prompt)

- **Style:** glossy stylised 3D cartoon, soft studio lighting, rounded forms, clean graphic
  shapes. Deadpan heroic sincerity — the tropes are played straight; the objects are the joke.
- **Brown rule (substitution substance):** all brown is CHOCOLATE — glossy, smooth,
  soft-serve-smooth, graphic-design brown (a paint stroke / marker line / chocolate smear).
  NEVER texture-realistic, never lumpy, never gross.
- **Palette:** porcelain white + warm gold light are the world; chocolate brown is the
  antagonist colour; **yellow is the SOLE accent colour** (rubber-glove gauntlets + kinetic
  type accent). No other accent colours.
- **Format:** ONE 16:9 (1280×720 plates), 24 fps master. Aspect stated in text on every
  generation call (video-api-mastery: unstated aspect follows the attached images).
- **Text:** ZERO readable text inside any still or clip — no letters, no words, no logos,
  no watermark. All typography is a post layer (Stage 6).
- **Licensed material:** none. Every character below is WuBu-native.
- **Adult-read rule:** every human figure is drawn with unambiguously adult proportions
  and faces — tall frame, mature facial structure (defined cheekbones and jaw, no round
  childlike cheeks), adult stature relative to props and doorways. No youthful features
  that read as a minor. When in doubt, age the figure UP.

## Lilypad visual language (applied per scene in SCENE_PLAN_v2.md)

Named techniques, each traceable to a source in `visual-forms/SOURCES.md` (entries 1–31)
and the @pixhell study (`research_notes/pixhell-20261107/report.md`):

- **Loose-prompt + strong curation** (@pixhell): one deliberately loose generation per
  volley for visual slots that want surprise (bridges, Outro, quest variety) — the
  bizarre outputs are kept and steered, not re-rolled into submission.
- **CRADLE SHOT** (@pixhell blind draw "cradle"): a carried/cradled subject as the seam
  between worlds — the Champion rides cradled in a sling/hammock/net that swings
  between set pieces, the pendulum swing hiding the cut. Transition device for bridges
  and the Outro.
- **Critic loop** (seeco / 0xnicc0 film-crew stack): contact-sheet QC on visual slots,
  score 1–10, fix worst 3, repeat until 8+. Runs at Stage 4 QC for visual-form slots.
- **Kinetic type as assembly layer** (visual-mv-forms Families A/D): words fly in post
  on the lyric onsets; never generated in-clip.
- **Montage / collage** (Family C): beat-matched montage for fast chant pile-ups;
  collage forgives style drift a clean cut exposes.
- **Code-rendered graphics** (Family G): deterministic counters/HUD (WIPE counter) as
  code/ASS layers — the counter ticks exactly ON the naming word.
- **Visualizer forms** (Family B, @slopAMPapp): audio-reactive accents keyed to the
  measured beat map for the instrumental Interlude and Outro.
- **Songs-first discipline** (@rearden_primus): the song grid is the contract; every
  visual decision answers to a measured song time.

## Anchor-still doctrine (Stage 4 inherits this)

WuBu's generator treats an image input as a STRONG CONDITIONER, never a frame source
(video-api-mastery, measured): outputs are fresh generations — "same scene,
re-rendered", MAE never near 0, end anchors land recomposed (MAE ~52 vs ~43 for
starts). So the F-chain is planned as **anchor pairs**, not pixel-pinned frames: each
clip is fired with start-anchor Fi (+ end-anchor Fi+1 where the journey recipe is
used), Stage 4 QC judges identity/composition carry, and assembly cuts on the landing.
Where a frame must appear EXACTLY (the loop close F00), the still itself is laid in
during editing — the generator will not reproduce it verbatim. Every still is generated
at 16:9 and the aspect is ALSO stated in text on every call. Read every ref back before
use (a drifted ref poisons every downstream take). **Never lead a two-image call with a
3:2 still** (v1 aspect lesson); 1248x704 is the pipeline's near-16:9 plate.
