## Graphics & assembly spec (Stage 6 contract)

- Picture: takes warped/trimmed per Slopcannon (lips scenes:
  phrase-level smooth warps, mouth anchors, hook mouth-open gate at
  L01/L02/L04/L12/L15/L23/L28/L31 onsets; motion scenes cut ON
  accents, 1–2f early).
- Type: kinetic_ass.py per section (SLAM/CASCADE/HIGHLIGHT/STACK per
  scene table) from SONG_WORDS.json arbitrated text.
- Counter/badge layer: PNG/ASS-drawn badge + digits, rendered per
  count-line event; badge pinned to phone corner by scene tracking
  notes (fixed screen-zone per scene, phone is thrust/held in a
  named zone in every phone vehicle).
- Glitch layer: RGB-split + frame-echo ffmpeg passes on chop spans
  (S03, S10, L24, S19 palette inversions via hue-rotate LUT swaps,
  S22/S30 breakdown), each hit ≤3 frames, ON S-tier accents.
- ZERO-STILL enforcement: (a) every take's used span must pass a
  motion scan (no near-dup run ≥2f inside the span at threshold
  mean-abs-diff <0.5 gray — pick spans accordingly); (b) graphic
  layers animate on every frame they cover (counter digits tick,
  badge pulses, type moves — no held cards); (c) any picture span
  that still risks a dup pair gets a moving overlay (drifting bubble
  PNGs / grain / light pulse); (d) MASTER GATE measures the whole
  master frame-by-frame: longest near-dup run must be ≤1 frame —
  reported in GATE json; a fail re-opens assembly, never ships.
- Post texture pass: house grain/vignette/sat −10–15%. GRAIN
  HONESTY RULE for the zero-still gate: the gate measures the
  shipped master (with grain) AND the pre-grain picture on every
  audited span; both numbers are reported. A span that passes only
  via grain is NOT a pass — it gets real motion (overlay drift,
  light pulse, re-trim) and is disclosed in the gate log.
