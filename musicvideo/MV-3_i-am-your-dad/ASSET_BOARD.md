## Devil's-advocate passes (summary)
- PASS 2 (attack): "corner preacher" risks reading as a real street-preacher
  likeness — killed as casting, kept as composition (lone figure, eye to
  camera) with the monster man, not a human preacher. "Chant leader" risks
  cult-imagery overtones — kept only as the pointing invitation mechanic;
  no robes, no crowd, no ritual staging. No crowd scenes anywhere: the
  joke stays one monster man addressing one viewer.
- PASS 3 (defend): the point motif survives — it is the song's own
  invitation ("say it with me / say it back to me"), not an imported trope.
- PASS 4 (worst case): dense mantra blocks (L26, L34) survive only as
  set-rotation scenes (S31–S33 change set per third) — a single static
  mantra scene would stall; the board forces a set change per block third.
