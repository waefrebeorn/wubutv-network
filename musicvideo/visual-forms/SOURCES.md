(1) Long-term *spatial*: a parallelized CNN-Transformer block (ResNet-101 features; CNN branch = texture/structure, Transformer branch = pixel-pair correspondence within the frame + semantic correspondence across the block's frames; each branch supplements the other; Transformer initialized from the VisTR video-segmentation network) and a **double-head non-local operation** — a vanilla head and an augmented head each warp the reference chrominance and emit their own warped colour + similarity map, and the colorization subnet combines whichever head did better per region. Losses: L1 (0.5) + perceptual (VGG19 relu5_2) + RAFT-flow temporal (3.0) + adversarial (0.2) + smoothness (4.0). Training: DAVIS + FVI + Videvo = 2,090 videos, clips ≤20 frames, first frame as reference, 384×216, 10 epochs on a single 3090.
    - **Measured (Table 1, vs DeepExemplar):** best FID (54.52 / 59.77), LPIPS (0.0621 / 0.0770) and PSNR (31.77 / 30.50) on DAVIS / Videvo. **The warp-error caveat, in the authors' own words:** FullyAutomatic and DeepRemaster score lower WE "due to their faded color" — as colour fades, adjacent frames differ less, so the temporal metric improves for the wrong reason. Ablations: removing Transformer + linkage degrades everything; removing the linkage alone holds image metrics but worsens WE (Figure 6: the moving horse fades without it); removing the augmented head degrades image metrics while WE *improves* — the same fading artefact in miniature. Block size N = 1…6 is quality-flat; N only buys speed (fastest N = 3 DAVIS / 5 Videvo).
    - **The two heads fail in different places (Figure 7):** vanilla (texture-driven) wins most cases including the dancer's face, but dyes plane lettering yellow (matches a yellow sign's letters) and tints grass brown (a brown patch in the reference); the augmented head (global features) gets those two right and fades the face. Neither is sufficient — the combination is the mechanism.
    - **Failure cases (paper's own §5.3):** (1) near-identical repeated objects in motion — a rotating carousel's horses move into each other's positions and are mistakenly correlated → inaccurate, inconsistent colour; (2) an object absent from the reference (a police car entering frame) cannot be colourized well — the conclusion's general form: "limitation due to strong dependency to reference image."
    - **Took (mechanics only):** (1) **carry state across the block boundary, explicitly** — the fix for long-horizon drift is a handed-over hidden state between blocks, not a better per-frame match; WuBu form: palette/grade state is an explicit object passed over the cut (last *state* → first *state*, the colour form of last-frame → first-frame chaining); (2) **two correspondence heads, combined** — local/texture and global/semantic matchers fail in different places; emit both warped results + both confidence maps and composite per region, never pick a global winner; (3) **price the temporal metric against fading** — any temporal-consistency check must be paired with a saturation-at-end check (end-of-span chroma vs start-of-span), or a desaturating rescue passes it; measurable in C11 from per-frame chroma means; (4) **repeated identical objects + motion = correspondence failure** — eye-check recolour rescues on repeated-subject takes (matching outfits, cloned crowd) first; the cut, not the matcher, is the fix; (5) **new object, no colour** — an object its plate doesn't contain is not exemplar-rescuable; re-draw the plate or cover with montage; (6) **small blocks compose via linkage** — short spans + an explicit state hand-over beat one long propagation pass (N buys speed, not quality); (7) **spatial long-term** — a colour decision consults the global palette (plate / section look) as well as the local match; local-only matching is the graffiti-wall fading failure.
    - **Adjudicated OUT / not adopted:** the network itself (ResNet-101 + Transformer + GAN training, 3090-bound; the C11 route is the classical shape — two-head correspondence + confidence + block linkage); whole-video colorization as a goal (the reference-dependency limitation stands; per-take rescue with state carried over the cut remains the scoped use); no prompting craft, start/end-frame, kinetic-type, or looping method exists in this node — none invented.
