# VERDICT LEDGER — the writing stack's memory of the user's verdicts

Created 2026-11-27 (writing loop fold, GAPS G9).

**The rule:** before drafting a show's next script, read this
ledger for that show's last verdict (the template §2 LEGIBILITY
block carries the Y/N line). A verdict indicts an ITEM — a rule, a
field, a failure class — and the item gets fixed in the standard or
the template. Verdicts are never re-argued, and a piece's internal
gates are never cited against the user's verdict: his playback
verdict outranks every gate, and this file is where that ranking is
recorded. One row per shipped/judged piece: what passed at lock,
what he said (verbatim, dated), and the item the verdict indicts.
