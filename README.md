# WuBuTV Network

The WuBuTV network repository — code, text, ledgers, slates, plots, and documentation.
Sole showrunner: WuBu. Every clip is a 10-second slice of life lore.

## The split

- **This repo (GitHub):** all code, text, ledgers, slates, pre-production drafts,
  research banks, learning log, plots, channel docs, TikTok policy/ledger/captions.
- **Media (Hugging Face dataset):** `WaefreBeorn/wubutv-network-media`
  https://huggingface.co/datasets/WaefreBeorn/wubutv-network-media
  — every shipped bumper, commercial, and episode clip, plus `manifest.json`
  (the full labeled catalog: number, title, tagline, channel, file path, CDN URL).

## Channels (exactly nine)

NEWS, ORIGINALS, SATIRE, LABS, MEDIA SCHOOL, PUBLIC ACCESS, PUPPET THEATER, NETWORK, ARCHIVE.
The Control Voice is furniture, not a tenth channel.

## Rules that never bend

- One item = one genuine 10-second scene: setup 0–3s, beat 4–6s, turn/tagline 7–10s.
- UNC never reacts. The hoodie reads exactly `~ WuBu ~` in yellow/gold.
- Native audio only. No licensed characters, no licensed footage, no licensed memes.
- A number with a finished clip behind it is a fact.
